# Наши листы нового дизайна

Листы, нарисованные нами в формате дизайнера (экспорт Dusk: cairo-SVG, 390 × 844, текст глифами-путями), там, где в наборе
дизайнера (`../all/*.zip`) нет листа для состояния, которое нужно приложению. Каждый выведен из листа дизайнера скриптом
из `scripts/design/`, не руками, чтобы рамка, шрифты и отступы остались дизайнерскими. `sosed/` и `neighbro/`
повторяют `<бренд>-static/mobile/` архивов.

| Лист | Из чего | Скрипт | Зачем |
| --- | --- | --- | --- |
| `w3_table-poker-{2,3,5,6}.svg` | `w3_table-poker.svg` (четверо за столом) | `poker-seat-sheets.py` | решение владельца 18.10.2026: дорисовать раскладки мест на 2, 3, 5 и 6 игроков |

Места покера: два ряда по краям панели, как у четверых дизайнера (я внизу слева, дальше по часовой), для пятерых и шестерых —
среднее место ровно посередине ряда. 2 и 3 — четверо с пустыми местами; 5 — шестеро с пустым верхним левым, так что
пришедший игрок никого не сдвигает. `scripts/measure-app-w3-games.sh` читает листы sosed рядом с дизайнерскими
(`OURS=` — другой каталог); листы neighbro нарисованы, но не замеряются (приложение сверяется с sosed).
