# Стенд замера модерации

Здесь выбирают, из чего собрать модерацию, — цифрами, а не спором. Это не часть
продукта: ни один файл отсюда не попадает в релей, пока замер не покажет, что
именно ставить.

## Зачем он вообще

Perspective API закрывается 31.12.2026 (см. [`../../docs/vendors-dpa_RU.md`](../../docs/vendors-dpa_RU.md)),
и модерацию решено делать своей моделью на своём узле. Тогда исчезает обработчик
из политики: текст сообщения не покидает инфраструктуру, договор ни с кем не
нужен, передача за границу не возникает.

Открытым остаётся вопрос **любого языка**. Писать могут на чём угодно, а
guard-модели знают немного языков: Llama Guard 3 1B — восемь, и ни русского, ни
греческого среди них нет.

## Что проверяем

Конвейер из пяти слоёв, где ни один не пропускает молча:

| Слой | Что делает | Чем взят |
|---|---|---|
| 1. Нормализация | NFKC, невидимые символы, растянутые буквы, leetspeak | свой код |
| 2. Определение языка | 218 языков, кодами, которые понимает переводчик | NLLB LID |
| 3. Лексика **по оригиналу** | ловит местную брань до того, как её причешет перевод | Toxicity-200, 200 языков |
| 4. Перевод в английский | и есть ответ «любой язык» — переводчик покрывает 200 | NLLB-200 distilled 600M |
| 5. Guard-модель | один язык, который надо сделать хорошо | Llama Guard 3 1B |

Порядок слоёв 3 и 4 — главное решение всей схемы. Машинный перевод обучен выдавать
гладкий текст и **отмывает брань**: грубое слово выходит вежливым словарным
эквивалентом. Поэтому список работает по оригиналу, до перевода.

Что делает решение, а не модель, — в `decide()` в [`pipeline.py`](./pipeline.py):
отказ по умолчанию. Язык не определился, перевод не удался, модель не ответила —
не публикуем. Ни одного пути, где сообщение проходит потому, что его не поняли.

## Как запускать

```sh
scripts/run-moderation-bench.sh build   # собрать образ, поднять guard
scripts/run-moderation-bench.sh run     # прогнать samples.jsonl
scripts/run-moderation-bench.sh shell   # внутрь контейнера
scripts/run-moderation-bench.sh clean   # снести вместе с кэшем моделей
```

Всё в Docker: ни модель, ни набор данных, ни пакет Python не ставятся на машину.
Контейнеру выданы **три ядра и 6 ГБ** — столько же, сколько у прод-узла
(Hetzner cpx22), иначе замер задержки был бы про другое железо.

Ollama слушает только `127.0.0.1`: модель не должна быть доступна снаружи даже на
рабочей машине.

## Про `samples.jsonl`

Это **дымовой набор, а не замер**. Его дело — доказать, что все слои работают и
что язык, которого никто не объявлял (тайский, арабский), всё равно проходит
конвейер. Метки в нём мои, и мерить по ним качество нельзя: получится оценка
модели по экзамену, который написал тот же, кто оценивает.

Настоящие числа дают наборы с человеческой разметкой — и они **уже получены**:
`evaluation.json` держит 300 размеченных примеров на язык по девяти языкам с
04.08.2026. Вывод из них сделан 27.08.2026 скриптом `summarize.py`, а решение
записано в `xor.ad/docs/chat_RU.md` §8.14: берём ветку **через перевод**, потому
что при едином пороге на все языки она не проваливается там, где ветка по
оригиналу падает до F1 0.404.

## Чем меряем на самом деле, и чего мы не знаем

Четыре уровня доверия, и каждый называется своим именем:

| Уровень | Чем меряем | Языки |
|---|---|---|
| Человеческая разметка | OGTD, Jigsaw, GermEval, PolEval, HatEval | en, ru, de, es, fr, el, pl · слабее uk, ro |
| Перенос | английский размеченный набор → перевод в язык → конвейер обратно | все 200 |
| Покрытие лексикой | механически, по спискам | все 200 |
| Жалобы | после запуска каждая жалоба — человеческая метка на своём языке | те, на которых пишут |

Второй уровень отвечает на вопрос «переживает ли оскорбление круговой путь через
перевод». Он **не** отвечает на вопрос «знает ли модель местный сленг» — и это
записано здесь, чтобы не потерялось в среднем числе.

Восемь языков из объявленных семнадцати (az, be, hy, ka, kk, ky, tg, uz) не имеют
публичной разметки вовсе. Для них есть только уровни 2–4.
