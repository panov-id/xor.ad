get/chatпостроено

Комната беседы (WebSocket)

Sec-WebSocket-Protocol предлагает `xor.p1, ticket.<t>` с билетом из POST /chats/{id}/ticket; узел отвечает xor.p1. Кадры идут только от узла к клиенту, в виде {type, seq, data}; тип message несёт {id, ciphertext, created_at}. Ждущее в очереди приходит при открытии, остальное — по мере записи. Коды закрытия: 4001 билет просрочен, погашен или не тот; 4002 сессия заморожена; 4004 не предложен xor.p1; 1011 ошибка узла; 1000 заменён новым сокетом той же сессии. 4003 беседа кончилась (закрыта руками или вышел срок). Ещё нет: 1001 при перезапуске (построено 21.09.2026).

Доступ

без доступа

Ответы

101Переход в комнату.
426Это не апгрейд до WebSocket.
