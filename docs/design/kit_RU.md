Редакция 3, 10.10.2026. Волна К (`docs/plan-goal-2026-10-10_RU.md`). Линзы: круг 1 — полнота 22, доступность 27,
единство 17; круг 2 — 30. Всё принято в текст, кроме отданного владельцу в §8.

этот текст, `web/src/ui/`, `depth/ink/kit.ts`. Только потом он попадает на экран. Ворота `check-web-kit`

## 2. Общие правила элемента

Каждый элемент в §3 — строка таблицы из шести обязательных полей:
1. **Имя** — откуда берётся доступное имя.
2. **Роль** и атрибуты.
3. **Клавиши.**
4. **Фокус** — куда встаёт и куда уходит.
5. **Цель** касания.
6. **Канал** — что, кроме цвета, несёт состояние.

Прочерк значит «неприменимо», пусто не бывает. `kit.spec.ts` проверяет каждую строку на `/kit`.

Общее, в строки не повторяется:
- **Фокус** — `:focus-visible`, кольцо `--focus-w` цвета `--focus`, отступ 3 px, у карточек `--card-focus-offset`.
  Правило 2 px в `styles.css:65` удаляется (К7б). Кольцо не уходит под TabBar и кнопку «написать»:
  `scroll-padding-bottom` на их высоту (WCAG 2.4.11).
- **Цель** — 44×44 по умолчанию («44» в таблице). Исключения: строчная ссылка в тексте (WCAG 2.5.8) и клетка доски 24 px.
- **Недоступное** — `aria-disabled="true"`, не `disabled`. Фокус ставится, причина словом рядом,
  связана `aria-describedby` (Н1).
- **Ожидание** — `aria-busy="true"`, подпись остаётся в дереве, итог `role="status"`.
- **Модальное** (ActionSheet, Confirm) — при открытии фокус на заголовке `h2` (`tabindex="-1"`), не на кнопке.
  Tab заперт внутри, Esc закрывает, фокус возвращается на открывшую кнопку.
- **Движение** — `--dur-1`, при `reduce` всё появляется за один кадр.
- **Тексты** — ключами словаря. Ни одного внутреннего id: «dots» → «точки», «ru» → «русские слова», «36» → «колода из 36 карт», «3x3» → «поле 3×3»,
  «stub: a link» → причина из словаря. Числа и даты — через `Intl`, множественное число — формами в ключах.

## 4. Терминал (depth)

Шаг К8 переводит экраны на `depth/ink/kit.ts`: экраны вместо своих `h(Box)` и `h(Text)` берут элементы кита.
Замер 10.10, `grep -o "h(Box\|h(Text"` по `depth/ink/*.ts`: `rooms.ts` 52, `screens.ts` 33, `move.ts` 17,
`table_boards.ts` 12, `table.ts` 11, `chat_game.ts` 9, `app.ts` 3, `parts.ts` 5 (останется в `kit.ts`). После К8 — только в `kit.ts`.

Правила лица:
- Цвет — терминала. Смысл несут слово и знак, `NO_COLOR` ничего не теряет.
- Фокус — `>` перед элементом и инверсия.
- Ошибка — строка «ошибка: …», не `!`.
- `DEPTH_PLAIN=1`: без альтернативного буфера, рамок `─│` и курсора `▋`, поток строк без перерисовки на месте.
- Подсказка клавиш — строкой текста внизу.
- Проверка диктором терминала НЕ ПРОВЕРЕНА, текстовый проход её не заменяет.
