## Что изменилось против v0

- **Посылка уровня 3 была неверной.** Ст. 16(6) DSA прямо допускает автоматику с
  раскрытием, ст. 17 требует только сказать об автоматике в мотивировке. Человека
  требуют: ст. 12(1) DSA — канал связи не только из автоматики; GDPR ст. 22(3) —
  право на вмешательство человека при значимом автоматическом решении о физлице;
  ст. 18 — суждение «подозрение угрозы жизни». Всё прочее, где у нас человек, держится
  на наших обещаниях: `sosed.place/landing/legal/terms_EN.md:87` и `:92` («taken by
  a person»). Нормы сверены по неофициальным копиям, EUR-Lex не открылся — этап 0.
- **Порядок.** v0 ставил юридические тексты первыми, но L1, L2 и L7 описывают правила,
  которые решаются в M2–M5. Теперь: решения по механике на бумаге → юр-тексты одним
  заходом → хранение и уборщики. Сторожа — отдельно и раньше всего остального, потому
  что снимают больше всего ручной работы.
- **Исправлены факты:** правила сообщества — 17 языков у `sosed.place` и 10 у
  `neighbro.place`, не «10 и 19»; P4 (один оффер, дубль) опровергнута панелью дня и
  из L1 снята; L6 не закрывается экранами — одна строка чеклиста про код; J9 и
  DSA-turnover вынесены за рамки со сроком 05.08.2027; добавлены выпавшие S10, S12, D12.

## Принцип: само, без нас

Три уровня: **1** — само по построению; **2** — само, обратимо, с мотивировкой,
человек смотрит по возражению или выборочно; **3** — человек обязателен.

Два правила для всей автоматики, записанных после панели:

1. **Истечение срока разбора не вводит и не снимает меру.** Мера кончается только
   своим сроком (пауза — 15 минут, скрытие — со смертью оффера). Иначе нарушитель
   подаёт возражение в пятницу вечером, а атакующий получает меру без решения.
2. **Автоматика не кормится бесплатными личностями.** Любой автоматический порог
   (скрытие, гашение, приостановка, пауза) считает только голоса личностей с
   принятой публикацией старше N часов, один голос на цель; таймаут очереди — не
   отказ.

**Уровень 3 после панели — только здесь:**

| Где | Почему не ниже |
|---|---|
| Прочтение каждого уведомления ради ст. 18 | суждение об угрозе жизни |
| Возражение на решение по уведомлению ст. 16 | по Р4 само решение может быть автоматическим с раскрытием (уровень 2); человек смотрит по возражению |
| Приостановка заведения-физлица | GDPR 22(3) — право на вмешательство; и SEC1: вход в порог — только `resolved` человека |
| Канал к человеку в поддержке | DSA ст. 12(1) |
| Вымарывание персональных данных в жалобе | редкое, суждение |

## Этап 0 — развилки и сверка норм (решения, без правок)

| # | Развилка | Где решается | Варианты — в вопроснике |
|---|---|---|---|
| Р1 | Третья ступень отлучки против срока беседы 260 мин | M2 | честная цена / ступень ≤ 4 ч / пауза своего срока / закрыть непереживающие беседы при уходе |
| Р2 | Решение по уведомлению без почты | L3 | как есть + юрист / квитанция на устройстве / квитанция + запасная строка |
| Р3 | Автоматика по заведению | A8 | автоскрытие офферов, `suspended` — человек / автоприостановка с возражением / как сейчас |
| Р4 | Обещание «решение по жалобе принимает человек» | L1 | держать / заменить раскрытием автоматики |
| Р5 | Шестой отказ в том же часе | M3 (E1b) | новая пауза сразу / пять проб после паузы (`posting_paused_until`) |

**Решено 14.09.2026:**
- **Р1 — третья ступень 4 часа.** `limits.tsv` `away.span.long` 8 → 4 ч. Беседа на 260 мин переживает уход, если своя реплика была не раньше чем за 20 мин; хранение недоставленного не растёт, L4 не переоткрывается; метка — `away_marked`, не `away_from`.
- **Р2 — квитанция на устройстве плюс запасная строка** «сотрёте данные браузера — решение не увидите, оставьте почту» (4.3).
- **Р3 — автоскрытие офферов, `suspended` ставит человек** по трём `resolved` за 90 дней; порог автоскрытия считает только давно публиковавшихся (2.4).
- **Р4 — обещание «решает человек» заменяется раскрытием автоматики** (3.1); человек — по возражению и при прочтении ради ст. 18. Риск ст. 16(6) «diligent, non-arbitrary» закрывается тем, что автоматическое решение называет класс и уходит с путём возражения, а сомнительное остаётся человеку.
- **Р5 — новая пауза сразу.** Чистое скользящее окно (`chat_RU.md:1461`, `:1465`): каждый отказ сверх пятого в том же часе ставит ещё 15 минут; пауза считается при чтении из `rejected_at_recent`, отдельной колонки нет. Текст паузы (3.2) и соглашения (3.1) говорят «пять отказов за скользящий час — пауза; каждый следующий в том же часе — снова пауза».
