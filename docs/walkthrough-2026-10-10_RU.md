Цель: прежде чем владелец сам тестирует продукт локально, его проходит Claude и записывает опыт.
Ветка `day59` @ `c2bde225` плюс незакоммиченные правки этой сессии.

## Как поднять

```bash
scripts/up-local.sh sosed      # страница http://localhost:4173, Mailpit http://localhost:62125
scripts/up-local.sh neighbro   # страница http://localhost:4183, Mailpit http://localhost:62135
scripts/up-local.sh down sosed # остановить и стереть данные
```

Стенд — это `docker-compose.web.yml` под отдельным именем проекта (`xor-local-<бренд>`). В нём база, миграции,
начальные данные, узел из текущих исходников, заглушка модели и Mailpit. Заглушка модели отклоняет только
ссылки, мессенджеры и контакты, остальное публикует. Настоящая модель — замер `relay/moderator`, к стенду она не относится.

## Чем проходил

Headless Chromium в контейнере, сценарий `textwalk.mjs`: два телефона 393×851, локаль ru-RU, без заголовков стенда
(оба с одного адреса, как двое соседей в одной Wi-Fi). На каждом шаге записывается текстом: id экрана, видимый текст,
элементы управления с их доступными именами, ответы узла от 400 и выше, ошибки страницы, время шага. Скриншотов нет
(владелец, 10.10). Первые прогоны со скриншотами удалены. Chrome не используется.

## Что прошло

Оба бренда, одинаково: заставка → «Кто вы» (имя, возраст, согласие) → ПИН → бумажный код (ввод 2-й и 4-й групп) →
пустая лента → фраза опубликована → фраза соседа в ленте → карточка → лайк → у второго «Мэтч!» → входящие →
мэтч (обе фразы, «Ждём ответа») → согласие второго → чат открыт, «на связи» → реплика туда → ответ обратно.
sosed — 7,7 с, neighbro — 8,4 с. Ни одного ответа узла ≥ 400, ни одной ошибки страницы.

## Что исправлено

Замер — headless Chromium в контейнере, коробки элементов на ленте sosed (`scratchpad/probe/feedbox.mjs`).

1. Отступ ленты под плавающую кнопку был задуман 152px (`web/src/screens/feed.css:58`). Но правило
   `.tabbed .screen { padding-bottom: 96px }` из `web/src/styles.css` той же специфичности подключается позже и побеждало.
   Правило ленты стало `.tabbed .screen[data-screen="feed"]`. До: отступ 96px, подпись 735–755, кнопка 723–775 — перекрытие.
   После: отступ 152px, подпись 679–699, кнопка 723–775.
3. Ссылкам задан цвет темы: `a { color: var(--accent-text); }` в `web/src/styles.css`. Замер: `rgb(152, 60, 34)` вместо синего браузера.
4. Заголовок вкладки — имя витрины. Плагин `xor-brand` в `web/vite.config.ts` заменяет `<title>`. Замер: `sosed.place`.

После правок зелёные: `check-web-tokens`, `check-web-types` (0 ошибок).

Заметил по ходу, не трогал: кнопка «написать» по стилю ленты — пилюля 327×52 (лист кита 03), а на экране она 64px шириной.
