# Test map

**Not maintained by hand since 2026-09-26.** The number of tests comes from
`scripts/count-tests.sh` (on `day58`, 2026-09-26: 739, of them `relay/node/test` — 692);
what each test guards is written in the test itself and in the `chat_EN.md` spec
next to the behaviour it describes. The former map of 22 flows, compiled on
2026-08-26 and counted up to B104, sits in
[`archive/test-map_EN.md`](archive/test-map_EN.md) and no longer witnesses the state.

Three rules stay in force (the project's `CLAUDE.md`):

- a test that has never failed proves nothing;
- behaviour is checked, not schema;
- say what was verified and how, and say plainly what was not.
