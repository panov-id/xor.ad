# sosed · дизайн 29.10.2026

Что внутри:
- `README_design.md` — дизайн-решения (стили, акцент, лайк-ладошка, ПИН, графика, время, слова). Это требования.
- `SCREENS_spec.md` — описание каждого экрана: тексты, состояния, поведение, широкие экраны.
- `screens/` — живые макеты: 4 стиля (kypros = Кипр, golden = Золотой час, ceramic = Керамика, paper = Бумажные заметки) × день/ночь × phone 390 / tablet 820 / laptop 1440. Один HTML = все 283 экранов подряд, шрифты встроены, анимации и плавающие значки живые.
- `png/` — те же экраны картинками (Кипр, день) для быстрого просмотра.
- `RULES_full.md` — полные правила 12 игр (тексты экранов «Full rules»).
- `HELP_tours.md` — шаги подсказок «?» для каждого экрана.
- `screens.csv` — номер, id, название, зона.
- `icons/` — 102 линейных значков SVG, сетка 48, толщина линии 2.3, цвет `currentColor`.

Порядок экранов совпадает с индексом приложения + состояния, добавленные при проработке: прокрутка ленты, помощь (тур по экрану), начало партии, правила, настройки стола, итог, подтверждение хода, увеличенная доска, чат в игре, нарды целиком, флот в морском бое. Экраны «Я» объединены (имя и возраст; кого я вижу).
